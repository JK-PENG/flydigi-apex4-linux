# 项目终止存档（2026-09-24）

**状态：按项目所有者决定，停止开发与实机验收。** 本文是最终状态入口；旧计划、
测试步骤和证据保留为历史记录，不构成继续运行游戏、写入 ForceAdapt、升级 SteamOS
运行时或开放生产默认值的授权。决定终止不等于证明硬件或方案在技术上不可能实现。

## 原目标与实际边界

原目标是把 PC 游戏向虚拟 DualSense/Edge 发送的原生动态扳机效果，经 Linux relay
转译为 APEX 4 实体 L2/R2 ForceAdapt。后来明确的日常使用目标是：无需逐游戏配置时
默认呈现 Edge 并开放经实体验收的通用效果；不向 Edge 输出的游戏才用启动选项临时
降级为普通 DualSense。**这个完整目标未达成。**

## 已取得的结果

- Linux/SteamOS 的基础 relay、虚拟 Edge、按键/摇杆/模拟扳机、四个独立背键、
  六轴运动、普通震动，以及 2.4G/有线的相关回归有实测依据；具体设备、连接和
  测试范围见 [验证记录](VALIDATION.md)，不能概括为所有硬件/游戏均通过。
- DualSense 输出报告解析、效果归一化、APEX 4 `0xA0` 命令构造、设备身份门禁、
  双侧 Normal 清除、限时状态管理、dry-run 和诊断工具已实现。2026-09-23 的
  mode 1 可观察性候选在本地和 SteamOS 各通过 186 项软件测试；这只证明软件
  门禁，不证明实体触感或游戏兼容。
- OW2/Proton 的普通 DualSense 身份曾产生 R2 `mode 2 → mode 1 → game Off`
  三轮原生游戏序列，持握者三轮均感觉到震动与阻力，松开后行程正常；仅限该
  游戏、身份、侧别、连接及安全参数。[实体证据](evidence/2026-09-21-bounded-native-session-physical.txt)
- 同一 OW2/Proton 对照中，普通 DualSense 收到动态扳机输出，而 Edge 动作窗口
  没有收到输出；这不是所有 Edge 游戏都不支持的证明。
  [对照证据](evidence/2026-09-20-ow2-native-game.txt)

## 未达成与负面证据

- `generic-safe` 是可选候选；**代码默认和最近一次有证据的 SteamOS 已安装状态均为
  `trigger_profile=disabled`**，从未提升为通用生产默认。虚拟 Edge 身份不等于
  默认启用实体自适应扳机。
- 2026-09-23 的独立通用 mode 1 实体测试中，L2 和 R2 虽有成功写入与自动 Normal，
  持握者均未感到阻力；L2 已知 mild 对照也未感到。物理按压与效果窗口尚未完整
  对时，原因未知；旧 OW2 正样本不覆盖这些负样本。
  [负面证据](evidence/2026-09-23-generic-candidate-steamos.txt)
- L2 mode 2 的一组 2.4G 参数有触感确认；mode 3、Galloping/Machine 未通过
  对应实体门禁。没有完成一款真实游戏向虚拟 Edge 输出动态效果并驱动实体扳机的
  整链验收。Proton 输入源过滤的当前游戏级行为也未完成最终验收。
- 同 fd `0xA0` echo 观察与完整输入时间轴已完成离线/软件准备，但没有后续
  实体观察。不能把软件测试、UHID dry-run 或 HID 写入成功写成触感通过。
  [软件证据](evidence/2026-09-23-mode1-observability-software.txt)

## 终止决定与原因

项目所有者决定不再继续开发。决定依据是：日常目标仍受通用阻力负样本、真实 Edge
游戏输出缺口和未验收效果类别阻塞；剩余工作不是简单的文档或配置收尾，完成时间
无法可靠承诺，继续投入与预期收益不匹配。通过 Proton 运行飞智空间站的想法仅做过
资料分析，没有安装或实测，不能作为已验证的替代路线。

## 运行与归档边界

最近一次有证据的 SteamOS 状态含候选运行时和用户服务，OW2 也曾使用专用启动选项；
本文**不把它们写成已清理**。项目所有者另行要求在存档推送后，核对并移除本项目的
SteamOS 安装、自动启动、相关配置和 OW2 启动选项。清理结果须有独立核验，
未知来源或其他用途的数据不应被一并删除。

本地开发分支及原始证据保留；公开归档应只发布通过隐私检查的快照，不能把含私人
提交元数据的未发布历史直接推送。终止后不再安排实体写入或游戏测试。
