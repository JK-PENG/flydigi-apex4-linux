## Candidate contract

`--trigger-bounded-native-right` selects the semantic translator and permits
one R2 cycle only. It preserves the captured mode change while applying fixed
caps:

```text
mode 2 rattle:     start<=60 pressure<=1 strength<=32 frequency<=21
mode 1 resistance: start<=60 strength<=40
total active deadline: <=1.0 second from the first accepted effect
```

The `0x26 -> 0x21` transition does not restart or extend the deadline. Game Off
clears early and latches the gate complete. L2, other modes and every later
cycle are ignored. Disconnect/disable abort the gate and normal relay reset
rules still apply. The effect is not accepted before the same-fd identity gate
has attached a verified APEX 4 transport.

For the captured Hanzo reports, the final candidate is:

```text
0x26 -> mode 2 (0,1,32,21,0)
0x21 -> mode 1 (0,40,0,0,0)
timeout or 0x05 -> Normal
```

This preserves rattle versus resistance and their game-driven timing, but caps
the decoded resistance strength 96 to the previously mild-tested strength 40.
It is therefore a bounded semantic approximation, not an unrestricted native
profile.

## Fixed wrapper modes

The game wrapper allowlists two explicit modes:

- `native-dry-run`: same policy plus `--trigger-dry-run`; cannot write;
- `native-write`: the physical policy described above.

Preview output states the side, both modes, caps, one-second total deadline and
one-cycle budget. The existing global setting cannot silently widen either
mode, and the bounded native CLI conflicts with unrestricted adaptive or other
bounded policies.
