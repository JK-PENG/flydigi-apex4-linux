## Wired native R2 sample

After exact authorization, Steam was stopped before the backed-up launch-option
change. The first launch request did not start OW2 or consume the one-cycle
budget; the announced fallback did. Before the holder action, only bilateral
connection Normal had been sent and the non-Normal count was zero.

```text
23:26:55.897  R2 mode 2 (0,1,32,21,0)
23:26:56.615  R2 mode 1 (0,40,0,0,0)  (+0.718 s)
23:26:56.901  L2 Normal, safety deadline
23:26:56.903  R2 Normal, safety deadline
```

There was no write failure or wrong-side effect. The holder confirmed both
vibration and resistance and confirmed normal R2 travel after release. This is
a bounded cable transport sample; it does not replace the 2.4 GHz three-cycle
game-Off acceptance.

After normal exit, OW2 and wrapper counts were zero, daily service was active,
manual service inactive, and one Edge/zero ordinary DualSense/one relay were
restored. Steam was stopped for an exact backed-up restoration to
`translation-dry-run`; `native-write` was absent and
`adaptive_triggers=false` after restart.

## Acceptance boundary

The E-stage targeted cable sample, returned-Edge paddles and live IMU regression
pass. Normal OW2 navigation and the holder's in-game action also exercise the
controller input path. Ordinary cable rumble and L2 mild output retain their
earlier physical evidence; this run did not repeat isolated motor or L2 writes.
OW2 still has no observed dynamic L2 report, so OW2 L2 remains N/A rather than
an inferred game feature.

Final machine state: OW2=0, daily active, manual inactive, one relay, one Edge,
zero ordinary DualSense, one translation-dry-run option, zero native-write
options and `adaptive_triggers=false`.
